# MS_Lab
Projekt dedykowany ćwiczeniom z narzędzi do automatyzacji budowy oprogramowania

## Funkcjonalności
- Działa
- Nie jest płynne
- Spełnia kryteria zadania
## Instalacja
```bash
# Klonowanie repozytorium
git clone https://github.com/MateuszSygut7/ms_lab.git
# Przejście do katalogu projektu
cd repozytorium
# Instalacja zależności
npm install
```
